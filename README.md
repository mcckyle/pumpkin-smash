# Pumpkin Smash

A small Halloween arcade game built with Python and Pygame.

Pumpkins fall from the sky. Smash them before they escape and avoid the ghost.

## Features

* Responsive pumpkin-smashing gameplay
* Increasing difficulty as the score grows
* Additional pumpkins unlocked at higher scores
* Ghost hazard that ends the game when clicked
* Animated pumpkins and explosions
* Atmospheric Halloween-inspired visuals
* Lightweight Pygame implementation

## Getting Started

### Requirements

* Python 3
* Pygame

Install Pygame with:

```bash
pip install pygame
```

### Run

Clone the repository, enter the project directory, and run:

```bash
python main.py
```

## Controls

**Mouse:** Click pumpkins to smash them.

Avoid the ghost.
